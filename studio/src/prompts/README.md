# Versioned creative prompts

- `planner.js` v2: one common campaign identity across all posts/networks/languages and a narrative per ordered sequence. Composition is a free-form suggestion, not one of three forced templates. No mandatory policy JSON, safe-area grid, logo shelf, fixed font sizes or copy-length budget is sent to the AI planner.
- `visual.js` v2: desired style, palette, shared identity, selected event facts, current frame/story and role-labeled image references. The model creates the entire finished visual including all supplied logos. Only the assigned photo is uploaded; information-only frames receive no event photo. A revision receives its previous image and original references. Full-canvas resizing adds no border, crop, duplicate logos or local typographic layout. Generated logo/text accuracy must be reviewed; pixel-exact logos are no longer promised for AI output.
- `social-copy.js` v2: natural channel-specific captions, suggested lengths, complete facts/URLs and source-backed public research when available. No style-guide character ceiling or truncation. Short complete messages need no padding. Research is untrusted evidence, never instructions or new event facts.
- `caption-research.js` v1: public format/date-only research, one Responses request with at most one `web_search` call. Only attested HTTPS sources from allowed domains are accepted. Check date and sources are saved/displayed. A 45-second timeout, malformed response, missing access or missing sources falls back explicitly to baseline advice; cancellation is preserved.
- `channel-styles.js`: channel adaptations of the same shared aesthetic, and model/quality configuration.

The planner and research start in parallel. Images depend on the planner and run two at a time; copy follows the research independently. Initial generation costs **3 text requests + N image requests**, plus the web-search tool fee. Revisions cost one new image edit; manual text edits cost no API request. No automatic retry, model downgrade or template substitution occurs.

Default image model: **`gpt-image-2.5-flare`, high quality**, checked against the [official SDK](https://github.com/openai/openai-node/blob/master/src/resources/images.ts) and [OpenAPI specification](https://github.com/openai/openai-openapi/blob/master/openapi.yaml) on 20 October 2026. GPT Image 2.5 accepts multiple original references and exact-aspect arbitrary dimensions divisible by 16. Do not send the legacy `input_fidelity` parameter: SDK documentation limits it to earlier models. Export sizes are reached by full-canvas resizing. Account model access, billing and possible verification must be checked with the provider; no live key is included in tests. The [Responses SDK](https://github.com/openai/openai-node/blob/master/src/resources/responses/responses.ts) documents web-search tools, source includes and structured text output.

Approval gates ZIP; regenerating resets that image's approval. New prompts cannot change existing raster images without a paid regeneration. Old snapshots remain historical records. The optional offline template/Java path retains its own deterministic renderer and separate layout rules. Change prompts here, increment versions and redeploy; never commit keys, real user addresses or confidential event samples.
