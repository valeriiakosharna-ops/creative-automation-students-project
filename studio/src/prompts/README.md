# Versioned creative prompts

- `planner.js` v3: one common campaign identity across all posts/networks/languages and a narrative per ordered sequence. Composition is a free-form suggestion, not one of three forced templates. No mandatory policy JSON, safe-area grid, logo shelf, fixed font sizes or copy-length budget is sent to the AI planner.
- `visual.js` v3: desired style, palette, shared identity, selected event facts, current frame/story and role-labeled image references. The model creates the entire finished visual including all supplied logos. Only the assigned photo is uploaded; information-only frames receive no event photo. A revision receives only the original logos and assigned photo, never a generated-image reference. Full-canvas resizing adds no border, crop, duplicate logos or local typographic layout. Generated logo/text accuracy must be reviewed; pixel-exact logos are no longer promised for AI output.
- `social-copy.js` v3: natural channel-specific captions, suggested lengths, complete facts/URLs and source-backed public research when available. No style-guide character ceiling or truncation. Short complete messages need no padding. Research is untrusted evidence, never instructions or new event facts.
- `caption-research.js` v3: public format/date-only research, one Responses request with at most one `web_search` call. The search requests JSON text without combining web search and a strict structured-output format. Only attested HTTPS sources from allowed domains are accepted. Check date and sources are saved/displayed. A 45-second timeout, malformed response, missing access or missing sources falls back explicitly to baseline advice; cancellation is preserved.
- `channel-styles.js`: channel adaptations of the same shared aesthetic, and model/quality configuration.

The outline and copywriter are independent. Each image still has its own multimodal frame plan. Images run two at a time. Initial generation costs **2 campaign text requests + N frame-reference planning requests + N image requests**. Optional public research is off by default and adds one Responses request plus up to one web-search tool fee before copywriting. Revisions with a verified frame plan cost one new image edit; older/missing plans add one frame-vision request; manual text edits cost no API request. No automatic retry, model downgrade or template substitution occurs.

Default image model: **`gpt-image-2.5-flare`, high quality**, checked against the [official SDK](https://github.com/openai/openai-node/blob/master/src/resources/images.ts) and [OpenAPI specification](https://github.com/openai/openai-openapi/blob/master/openapi.yaml) on 20 October 2026. GPT Image 2.5 accepts multiple original references and exact-aspect arbitrary dimensions divisible by 16. Do not send the legacy `input_fidelity` parameter: SDK documentation limits it to earlier models. Export sizes are reached by full-canvas resizing. Account model access, billing and possible verification must be checked with the provider; no live key is included in tests. The [Responses SDK](https://github.com/openai/openai-node/blob/master/src/resources/responses/responses.ts) documents web-search tools, source includes and structured text output.

Approval gates ZIP; regenerating resets that image's approval. New prompts cannot change existing raster images without a paid regeneration. Old snapshots remain historical records. The optional offline template/Java path retains its own deterministic renderer and separate layout rules. Change prompts here, increment versions and redeploy; never commit keys, real user addresses or confidential event samples.


`frame-planner.js` v1 is a new multimodal per-frame planning prompt. It inspects every logo and ONLY the assigned photo, via `visual-references.js`. The global outline has no image attachments and cannot decide source IDs. The app's allocation module controls the unique photo bindings. Frame-plan output is sanitized; no model-controlled photo/asset reassignment is accepted. Invalid/missing reference plans block the corresponding image call; other frames continue.

The global outline, per-frame planner and image generator all request light backgrounds, no invented/additional/replaced people and no CTA. On a no-photo frame, only logos are attached and an abstract/typographic image without people is requested. On a photo frame, only that original photo may supply people/photography. Logos never act as human references. Generated-image references are excluded even for revisions. Feedback refines the same plan/originals; a missing/old plan is created once before regeneration.

The default budget is 2 campaign text calls + N frame vision plans + N image edits. Enabling optional research adds 1 Responses call and up to 1 web-search tool fee. Planning previews are downscaled to at most 1024 px, decoded sequentially; originals remain untouched for image edits. No automatic paid retry is made. Review model fidelity; these safeguards do not promise perfect generative identity preservation.
